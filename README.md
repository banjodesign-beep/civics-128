# Civics 128 · v1.1

Plain HTML/CSS/JS. No build step. Netlify: publish directory = repo root, no build command.

## Files (all at the top level of the repo)
- index.html: the app
- apple-touch-icon.png (180x180, no transparency): iPhone home screen icon
- icon-192.png, icon-512.png, manifest.webmanifest: Android / installable app icons
- favicon-32.png: browser tab icon

## What's new in 1.1
- Full-bleed home screen icon (navy, gold star, 128, flag stripes). No white edges.
- Animated splash on launch: fireworks, waving stripes. Shows once per launch; tap to skip.
- Keep going: after each 10, continue with 10 more in the same session. Session score carries across rounds.
- Mastery tab: accuracy per round over time, 5-round average, 60% pass line, level ladder, accuracy by section, table by day.
- Fireworks when you pass a sample test or get a perfect 10.

Progress from v1.0 is kept (same storage). Answers made before 1.1 show as a starting baseline on the Mastery tab.
